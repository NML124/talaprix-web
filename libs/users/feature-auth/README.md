# users-feature-auth

This library was generated with [Nx](https://nx.dev).

## Supabase OAuth local

For Google OAuth to return to the application, add
`http://localhost:4200/auth` (or `http://localhost:4200/**`) to the Supabase
Authentication Redirect URL allow list. Google credentials stay configured in
Supabase and are never added to the browser client.

## Running unit tests

Run `nx test users-feature-auth` to execute the unit tests.
